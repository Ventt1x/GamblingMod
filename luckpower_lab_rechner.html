Verwendete Mathematik

k = curveFactor · [1,2 + 2,2 · exp(−½ · ((P₀ − 50)/25)²)]

F(x,k) = [1 − exp(−k · x/100)] / [1 − exp(−k)]

0 ≤ L ≤ 100:
P(L) = P₀ + (Pₘₐₓ − P₀) · F(L,k)

−100 ≤ L < 0:
P(L) = P₀ − (P₀ − Pₘᵢₙ) · F(|L|,k)

Außerhalb ±100: Übergang über T = 20 Luck, anschließend linear.
t = Abstand über ±100, r = linearFactor, m = Tangentensteigung (Betrag)

0 ≤ t ≤ T:
Δ(t) = m · [t + (r − 1) · (t²/T − t³/(3T²))]

t > T:
Δ(t) = m · [T · (1 + 2(r − 1)/3) + r · (t − T)]

Rechts: P = min(100, Pₘₐₓ + Δ)
Links: P = max(0, Pₘᵢₙ − Δ)

m₊ = (Pₘₐₓ − P₀) · k · exp(−k) / [100 · (1 − exp(−k))]
m₋ = (P₀ − Pₘᵢₙ) · k · exp(−k) / [100 · (1 − exp(−k))]

Bei −100 und +100 stimmen Funktionswert und Steigung jeweils überein. Der Steigungsfaktor wirkt nach einem glatten Übergang über 20 Luck-Punkte vollständig. Die endgültige Begrenzung auf 0 % bzw. 100 % erzeugt dort, wo die Gerade diese Grenzen erreicht, einen Knick. Wenn die Tangentensteigung 0 ist, kann der entsprechende Endwert unerreichbar bleiben.
